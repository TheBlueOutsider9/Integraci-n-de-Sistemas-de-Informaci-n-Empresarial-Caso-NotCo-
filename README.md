# Integraci-n-de-Sistemas-de-Informaci-n-Empresarial-Caso-NotCo-
Propuesta de diseño e implementación del ERP SAP S/4HANA Cloud para la FoodTech NotCo. El proyecto busca eliminar silos de información conectando el núcleo de IA con logística, compras y finanzas. Incluye modelado AS-IS/TO-BE, evaluación TCO/ROI y diseño de KPIs.
